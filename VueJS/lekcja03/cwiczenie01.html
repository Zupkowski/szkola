Część 1: Iteracja po tablicach (v-for)

Pętla po prostych tablicach:

  • {{ item }}

Tablica z indeksem (item, i):

  • {{ i }}: {{ item }}

Pętla po tablicy obiektów:

  • {{ i }}: przedmiot: {{ item.subject }}, ocena: {{ item.grade }}

Część 2: Iteracja po obiektach (v-for)

ul 1 - value key object

  • {{ key }}: {{ val }}

ul 2 - key value index obiektu

  • {{ i }} - {{ key }}: {{ val }}
